# Football Tracker v2.6.6

This patch removes Cup stage XI analysis and consolidates League Race/XI presentation. The v2.6.5 selection policy is preserved.

## Competition changes

- League Players has one **League Awards** section and one **First Half / Second Half / League** selector. It controls one Top 5 Award Race, its existing View All destination, the existing official 4-3-3 XI and MVP, and the selected scope's completion status.
- First entry, absent values and invalid or retired selections default to League. Valid stored half selections survive reload, player/Race return navigation and season changes. No state field is added.
- Cup Stage XI, Player of the Stage, their selector and dedicated computation are removed. Cup overall Race/XI/MVP and finalized scorer, assist and goalkeeper awards remain, together with general rankings, table/stage/replay data and progression.
- Obsolete device-only `bestXiMode` and `cupAwardStage` fields are no longer written or restored. Existing stored fields are safely ignored; durable football data is not migrated.

## Shared evaluation and scope safety

Race and XI receive the same selected `CanonicalAwardResult` and candidate array. The established scope evaluator remains in use for all three League tabs. Review found and fixed a proposed reuse of the general standings model: preserved legacy teams can make that model's completion status differ from the official sixteen-team scope. A dedicated real-data regression now verifies finalized status and Top 5/View All consistency with an extra retained team.

The separate full-League individual-stat model stays unchanged. Existing memoization and bounded award caches stay unchanged. Cup's unused stage evaluation and unused Best XI match-scope lookup are removed. No new cache, library or calculation engine is introduced; CPU performance gains are not claimed without a timing comparison.

`performanceAwardResult` remains because existing lazy analytical compatibility paths and rating tests still use it. The generic Cup/Champions period matcher and final-replay handling also remain. The unused Cup award-stage option helper is removed. Remaining old selectors in tests deliberately verify legacy restoration or absence; there is no active Cup Stage XI UI or calculation path.

## Preserved behavior

Award policy revision **3** and Rating revision **13** are unchanged. Official Best XI formulas/eligibility, MVP, official events and derived Records/Home/News/Player/Team honors are unchanged. Team History selection, shared Race sorting/filters and all shared pitch components/styles are unchanged.

The source diff is limited to Competition presentation, device-only scope/default restoration, the Cup-exclusive option helper and version metadata. Rating/MOM, Match Log, registration/roster/transfer/release, general statistics, standings and tournament rules, durable schema/storage keys and Supabase synchronization have no source changes. No dependency is added.
