# Football Tracker v2.6.4

## Team History

- Individual Honors uses the existing full-name helper before saved-name and
  historical fallbacks. Registration's compact `name` no longer overrides
  `fullName`. Counts, moment badges, disclosures and Player Detail links remain.
- Best XI always uses a 3:4 pitch. Player icons remain40px; names, rating badges,
  crests and goal/assist labels keep their existing sizes and information.
  Team-only badge offsets and coordinates make room without enlarging the pitch.
- Four-or-more DEF/MID places are ordered using actual scoped LB/RB or LM/RM
  minutes. Distinct edge assignments maximize combined relevant minutes; ties
  preserve selection order. Selection, scores, quotas and eligibility are unchanged.
- Five-player groups use zigzags; larger groups use multiple rows. Large goal/
  assist counters use spare physical rows where available. Existing official
  Best XI and Match Log/input Pitch presentation stays unchanged.

## Measured calculation changes

- Latest Changes skips generating match-performance events it would discard;
  the default News/Match Changes API still includes them.
- News iterates actual participants in original roster order, preserving first
  appearances, duplicate identities and event order. Player milestones skip
  unrelated matches while keeping career chronology.
- Historical Cup/Champions checkpoints reuse the last official result while
  completion is provably pending. All winner, integrity, tie and replay decisions
  remain with the original engines; ambiguous records conservatively fall back.
- League History uses caller-owned transient rating/credited-team/shot facts
  across its prefix tables. It retains canonical standings and replays individual
  values in the original addition order. No persistent cache layer is added.
- See [paired measurements](performance/v2.6.4.md) and
  [raw samples](performance/v2.6.4-engine.json). Full result comparisons against
  e97d391 include ordered Maps, event contents/IDs and changed/deleted histories.
