# Football Tracker v2.2.12 Refinement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v2.2.12 navigation, ranking-filter, readability, and targeted-performance refinement without changing football-domain behavior.

**Architecture:** A shared compact `PositionFilter` writes existing navigation-entry screen state and each ranking screen passes its historical position family into the existing ranking index before sorting. Root navigation owns durable in-memory scroll restoration with bounded animation-frame reachability retries and a dedicated Team Detail-to-Teams reset. Match Detail consumes canonical cached derived outputs through a single memoized read model and renders canonical per-player change groups with visual priority.

**Tech Stack:** React 19, TypeScript, Vite, Node built-in test runner, Tailwind utility classes.

**Spec:** User-approved v2.2.12 refinement brief in this conversation.
