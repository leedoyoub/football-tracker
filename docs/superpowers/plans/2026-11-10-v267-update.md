# Football Tracker v2.6.7 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Preserve every existing record and calculation while delivering the requested player tabs, accessible Back, safe match metadata edits, sortable consistent tables and measured performance improvements.

**Architecture:** Reuse canonical competition identities, official engines, existing caches and durable same-ID save. Sorting is a presentation projection. Player tabs mount separate calculation trees. Optimize only measured paths, retaining all outputs.

**Tech Stack:** Existing React 19, TypeScript 6, Vite 8, localStorage primary / IndexedDB mirror / optional Supabase queue. No new dependencies.

**Spec:** [Original user specification](../specs/2026-11-10-v267-request.md). User explicitly waived additional design approval and requested continuous implementation through main push and deployment verification.

## Global Constraints

- Target version exactly 2.6.7; bump only after implementation and validation.
- Rating REV13 and award policy revision 3, 90-minute cap and official tournament/statistical semantics remain unchanged.
- Never delete user changes, historical IDs, records, events or features to improve performance.
- Preserve League table dimensions, typography, columns and combined GF-GA. Cup keeps combined W-D-L/GF-GA widths and every status/line/replay feature.
- New stat sort defaults: P/W/D/GF/GD/Pts descending; L/GA ascending. Ties use original official rank; # restores original order; source arrays remain untouched.
- Match edits retain ID, recordedAt, event IDs/sequences/minutes, substitutions, historical player references and lineup. Score remains event-derived.
- Cancel/failure preserves durable records and unrelated drafts. Revalidate source and target at queued durable write time.
- No live user database/browser storage modifications for testing. Use deterministic synthetic fixtures and isolated browser profiles.

## Review Focus

- Champions G1 moved while G2 remains: block gaps even within the same round.
- Destination slot occupied during a queued save: revalidate latest state before writing.
- Deleted/transferred/released players: preserve original appearance IDs and recorded team scope.
- Player tab switch immediately followed by navigation/Back: retain tab, filter and independent scroll checkpoints.
- Cup stat sorting across survival boundary: retain official statuses and show a non-positional boundary description.
