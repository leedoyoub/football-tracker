# Football Tracker v2.6.4 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for integration and
> independent domain workers for the measured News/analytics/layout tasks.

**Goal:** Fix Team History names and fixed-size placement while reducing measured
News/Latest Changes calculation cost without changing football results.

**Architecture:** Keep the existing selector and official engines. Reuse cached
position minutes for a separate display assignment; optimize existing derivation
loops and gate provably incomplete historical checkpoints conservatively.

**Tech Stack:** React, TypeScript, existing Node test harness, Vite, Oxlint.

**Spec:** [design](../specs/2026-10-22-v2.6.4-design.md), derived from the user's
complete supplied requirements.

## Global constraints

Fixed 3:4 Team History pitch; 40px player icons and unchanged text/badge/stat sizes.
Preserve selected players, REV13, policy 2, MOM, official awards, storage, PWA and
competition rules. Baseline e97d391; release 2.6.4. No speculative cache layers.

## Review focus

- Multi-role left/right candidates cannot occupy both edges or change selection.
- Duplicate/legacy knockout slots must retain exact event timing through fallback.
- Same-array item replacement and earlier-match deletion invalidate later results.
- Missing/released players and empty XI slots preserve labels and navigation.
- Long names, large rating/star badges and stats must be included in mobile bounds.

cycle. Performance measurements run without concurrent CPU-heavy verification.

commit, deployment and any remaining verification limits.
