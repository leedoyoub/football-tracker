# Football Tracker v2.5.7 검증 및 배포 보고서

기준: v2.5.6 / `e4ee68f3ab35e2a0d308672b313a149f1d0da0b9`. 작업일: 2026-10-12 KST.

## 구현 결과

1. Competition의 Players/Table/History/Matches/Bracket을 공통 RankingMetricTabs의 navigation 크기(최소 36px, 12px 글자)로 통일했다. 내용 너비, 가로 스크롤, 선택 항목 노출을 지원한다. 최상단 League/Cup/Champions 선택 버튼과 각 대회 기본 메뉴는 유지했다.
2. League Overall/Form, Cup Stage/Total은 기존 metric 크기의 작은 pill을 사용한다. Form의 Last 5 도움말과 계산을 유지하고 Total은 스크롤 영역 밖에 고정했다.
3. Team Detail Matches는 기존 ResultCard를 재사용한다. 조회 중인 팀 기준으로 점수·승무패·상대 팀을 표시하며 League/Cup 양 팀 귀속, Champions recorded-team 귀속, 시즌/대회 필터, 최신순, 중복 제거와 원래 match ID 이동을 검증했다.
4. League History의 native range에만 어두운 track, emerald 진행/손잡이, 36px 입력 영역과 focus 표시를 적용했다. WebKit/Firefox 스타일을 포함하고 min/max/value 및 native 이벤트를 유지했다.
5. Player Rank Trend의 최초 선택을 Overall로 변경했다. Position/Team과 각 metric 계산은 유지했다.
6. Player Detail 대회 범위는 All/League/Cup/Champions 단일 선택 pill로 바꾸고 시즌 dropdown, 진입 경로의 초기 scope, 변경 시 metric reset, Back 처리를 유지했다.

REV13, Rating/MOM/공식 순위/수상/Last 5 계산, 엔진·selector·cache 구현, 저장 schema와 `football-tracker-v1`은 변경하지 않았다. Home/Results/Competition의 기존 ResultCard 구현과 결과도 변경하지 않았다. 새로운 다중 선택이나 필터는 추가하지 않았다.

기존 benchmark를 v2.5.6과 현재 독립 모듈 그래프에서 동일 프로세스에 7회 교대 실행했다. Fixture는 16팀 × 23명, 현재 선수 367명, 2시즌 1,152경기다. [전체 20경로 원시 표본과 p95](v2.5.7-benchmark.json). 아래는 CPU 파생 계산 median(ms)으로 브라우저 화면 진입 시간이나 FPS가 아니다.
