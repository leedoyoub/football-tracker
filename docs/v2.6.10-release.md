# Football Tracker v2.6.10

기준은 v2.6.9 최종 커밋 `9abefd39e21c0d0a35601b50818eacd148d4317d`다. 작업 시작 시 main과 작업 트리가 깨끗한 것을 확인했다. 기존 구현과 저장 데이터를 초기화하지 않았다.

## 선방 표시

Player Detail → Matches의 기존 득점·어시스트 영역에 공식 선방이 1회 이상일 때만 `🧤 숫자`를 추가한다. 장갑을 횟수만큼 반복하지 않는다. 0회에서는 기존 표시와 카드 구조가 유지된다. 득점·어시스트와 동시에 표시할 수 있고, MOM의 파란 평점·별, Rating Details와 경기 상세 이동은 유지한다.

현재 명단에 없는 선수의 `SavedPlayerMatches`에도 같은 표시를 적용했다. 두 경로 모두 기존 `src/engine/playerMatchFacts.ts`의 `playerSaveCount(match, appearance)`를 직접 사용한다. 등록 포지션으로 제한하지 않고 실제 출전 구간의 GK 역할, 포지션 변경·교체, event.count 및 count가 없는 레거시 이벤트를 기존 공식 규칙대로 처리한다. 새 계산 알고리즘이나 캐시를 추가하지 않았다.

경기 카드 렌더링 시 해당 경기·선수의 선방만 읽는다. 전체 선수 통계를 다시 계산하는 경로는 추가하지 않았다. 새 표시에는 `whitespace-nowrap`와 선방 횟수 접근성 레이블을 적용했다. 경기 객체 교체 후 재렌더링에서도 기존 캐시 값에 의존하지 않고 최신 선방 수를 표시한다.

## 변경 파일

- `tests/helpers/v2610-saves-fixture.cjs`, `tests/v2610-player-saves.test.cjs`: 숫자를 수작업으로 확인한 실제 기록·렌더링 회귀 테스트 15개.
- `tests/v2610-player-saves.browser.cjs`: 모바일·데스크톱 일반/명단 제외 선수 표시, 이동 및 저장된 수정 수치의 새로고침 검증.
- `src/config.ts`, `package.json`, `package-lock.json`: 2.6.10 일치. 기존 릴리스 테스트와 공개 배포 테스트의 버전 기대값도 일치시켰다. 기존 검사 기준은 유지한다.
- `docs/superpowers/plans/2026-11-13-v2610-player-saves.md`: 구현·검증 기록.

## 검증 기록

새 테스트는 구현 전 양수 선방 표시 누락으로 10개가 실패했고, 최소 구현 후 모두 통과했다. 기존 Player 테스트와 합쳐 20/20을 확인했다. 0·1·여러 회, count 합산, count 없는 레거시, 잘못된 count/선수/팀/역할, 등록 CB의 실제 GK 출전, 경기 중 GK 변경, 교체 출전, 동일 경기 ID의 1→6→0 수정, 득점·어시스트 동시 표시, 공식 MOM·평점·이동을 검사한다.

실제 production Chromium에서 320/375/390/1280px × 일반/명단 제외 선수의 8개 조합이 통과했다. 선방 숫자와 줄바꿈 방지, 페이지 가로 넘침 없음, MOM·득점·어시스트·경기 상세 이동을 확인했다. 격리 기기의 저장된 선방을 9회로 바꾸고 실제 reload 후에도 모든 조합에서 9회를 확인했다. 모바일 화면을 이미지로도 확인했다. 물리적 iOS/Safari·Android 기기 검증을 의미하지 않는다.

브라우저 fixture에 공식 역할 조건을 위반한 이벤트가 포함되어 기존 저장 검증기에 거부되는 문제를 발견했다. 브라우저 저장용 fixture만 유효한 기록으로 수정하고, 잘못된 이벤트에 대한 직접 단위 테스트와 원래 저장 검증기를 유지했다. 버전 갱신 시 남아 있던 기존 테스트 정규식 두 곳도 2.6.10으로 맞췄다.

최종 전체 자동화 테스트는 **1,386/1,386 통과**, 실패·취소·건너뜀 0건이다. TypeScript 검사, Lint(종료 코드 0·오류 0·경고 44), production build와 `git diff --check`도 통과했다. 기존 릴리스의 큰 단일 번들 경고는 유지된다.

기존 v2.6.9 Player 브라우저 테스트도 원래 검증 기준 그대로 네 폭에서 통과했다. MOM/일반 평점, Recent Form 점·숫자·Enter/Space 이동, 실제 터치 스크롤·탭과 드래그 억제, Rating Details와 페이지 경계를 확인했고 런타임 오류는 0건이다. 보고서 출력만 격리 경로로 바꾸어 기존 v2.6.9 측정 파일을 덮어쓰지 않았다.

실제 서비스 워커의 bypass를 끄고 오프라인 reload하여 Matches 탭·대회 필터와 1,152개 경기 ID 보존을 확인했다. 단위·브라우저 테스트의 숫자는 변경하지 않은 공식 선방 함수와 수작업 기대값 모두에 일치한다. 독립 코드 감사의 버전 정규식 지적은 수정 후 회귀 테스트로 검증했고, 브라우저 수정 후 reload 검증도 보강해 통과했다. 남은 Critical/Important 결함은 없다. Windows가 일부 격리 Chromium 임시 프로필의 파일 핸들을 유지해 정리가 지연된 경고는 기능 검증과 구분한다.

## 기존 기능 보존

엔진·Rating REV13·MOM·공식 통계·Awards/Records·Best XI·리그/컵/챔피언스 규칙·동률 정책은 변경하지 않았다. Recent Form과 그래프 이동, 포지션/팀 복수 필터, Swipe Back·일반 Back·Scroll-to-Top, 저장 스키마·localStorage/IndexedDB/Supabase·드래프트·Import/Export와 기존 성능 최적화도 변경하지 않았다. 실제 사용자 DB나 브라우저 프로필에는 접근하지 않았다.
