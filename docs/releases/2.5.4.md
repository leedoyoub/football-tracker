# Football Tracker 2.5.4

Patch release with focused performance and loading improvements.

- Reuse per-match player appearance and position interval indexes while calculating combination statistics.
- Load screens through route-level dynamic imports and show a loading fallback while a screen chunk arrives.
- Keep lazy screen failures inside the existing startup recovery boundary.
- Keep Rating REV13, competition rules, storage keys, cloud protocol, and saved match data unchanged.
